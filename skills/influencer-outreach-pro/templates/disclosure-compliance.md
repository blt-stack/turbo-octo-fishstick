# Disclosure Compliance

The legal + platform layer. Required FTC + platform-specific disclosure language per relationship type. The skill embeds this in outreach so creators see the expectations upfront.

## US FTC requirements (apply to all US-targeting content)

The Federal Trade Commission requires "material connection" disclosure when:
- A brand pays a creator
- A brand gives a creator free product
- A brand provides any value (discount, early access, affiliate commission)

This applies regardless of platform.

## Disclosure language per relationship type

### Gifted product only

| Platform | Required disclosure |
|---|---|
| Instagram | "#gift" or "thanks to [brand] for sending this" in caption + first sentence |
| TikTok | Verbal mention in video + "#gift" in caption + Branded Content toggle (recommended) |
| YouTube | Verbal in first 30 seconds + "I received this product from [brand]" in description + "#gift" |
| X / Twitter | "#gift" or "thanks @[brand]" in the post |
| LinkedIn | "Thanks to [brand] for sending [product]" in the post |
| Pinterest | "Thanks to [brand]" in Pin description |

### Hybrid (product + payment) or fully paid

| Platform | Required disclosure |
|---|---|
| Instagram | "Paid partnership with [brand]" tag (Instagram's built-in branded content tool) + "#ad" or "#sponsored" |
| TikTok | "Branded Content" toggle MUST be on + "#ad" + verbal disclosure |
| YouTube | "Paid promotion" toggle MUST be on (legally required) + verbal in first 30 seconds + "#sponsored" or "#ad" |
| X / Twitter | "#ad" or "#sponsored" in the post |
| LinkedIn | "#ad" or "#sponsored" + clear statement of paid partnership |
| Pinterest | "Paid partnership" disclosure in Pin description + "#ad" |

### Affiliate (commission on referrals)

| Platform | Required disclosure |
|---|---|
| All platforms | "#affiliate" + statement that the creator earns commission ("This link gives me a commission") |
| Plus YouTube | "Contains affiliate links" in description |
| Plus IG | Affiliate disclosure in caption |

## The skill's embedding approach

The skill includes the disclosure expectation in the outreach explicitly. Example:

```
[In the offer section]

"We'd send the kit + $200 for one Reel + 2 Stories.

For disclosure, we ask that posts use Instagram's 'Paid partnership' tag and include #ad in the caption — happy to walk through this if it's a first time."
```

This:
1. Sets expectations upfront (no creator surprise)
2. Signals brand sophistication (creators trust brands that know compliance)
3. Removes the "we didn't realize" excuse later
4. Helps the creator avoid getting flagged by platform algorithms or FTC

## Disclosure language NOT to suggest

- "Honest review" — FTC has been clear this isn't enough; full disclosure required
- "Sent to me by [brand]" — better as "Gifted by [brand]"
- "Special thanks to [brand]" — too vague; doesn't meet FTC standards
- Disclosure hidden at end of long caption — FTC requires "clear and conspicuous" placement (top of caption preferred)
- Disclosure-only in hashtag list at the bottom — courts have ruled this isn't sufficient

The skill flags any creator-suggested disclosure language that doesn't meet these standards before brand signs off.

## Region-specific variations

### UK (ASA — Advertising Standards Authority)

Same general principle as FTC but stricter on early-caption placement. Required language often includes "ad" not just "#ad" (without the hashtag).

### EU (DSA — Digital Services Act + local consumer protection laws)

Requires "Advertising" / "Werbung" / "Publicité" in the local language. Hashtag-only disclosures don't always satisfy EU requirements.

### Brazil (CONAR)

Requires "#publi" or similar local-language disclosure.

### Mexico

Requires Spanish-language disclosure ("#publicidad" or "#anuncio").

The skill defaults to US/UK English-language disclosures and flags when content will reach other regions where additional compliance applies.

## Platform-side enforcement

Different platforms enforce disclosures differently:

| Platform | Enforcement |
|---|---|
| Instagram | Algorithmic detection + manual review; can shadow-ban undisclosed sponsored content |
| TikTok | Branded Content Toggle enforcement is active; algorithm penalty for missing toggle |
| YouTube | "Paid promotion" toggle legally required; YouTube monetization can be affected |
| X / Twitter | Lighter enforcement; FTC enforces directly |
| LinkedIn | Lightest enforcement; FTC enforces directly |
| Pinterest | Light enforcement; FTC enforces directly |

The skill is realistic about enforcement but encourages compliance regardless — non-compliance is brand risk + creator risk + erodes trust with audiences.

## Disclosure brand checklist

When the outreach is sent, the skill includes a brief disclosure checklist for the brand:

```
DISCLOSURE EXPECTATIONS FOR THIS PARTNERSHIP
✓ Creator should use platform's built-in paid partnership tag
✓ Caption should include #ad or #sponsored at the start
✓ Video content should verbally mention the partnership in first 30 seconds
✓ For YouTube specifically: 'Paid promotion' toggle must be on
✓ Affiliate links (if used) should be disclosed separately

We'll review content before publication if helpful. Want to confirm fit on disclosures?
```

This serves as the brand-creator agreement — creator sees the expectations + asks questions upfront.

## When disclosure is the deal-breaker

Some creators decline to do paid partnerships specifically because their audience reacts negatively to #ad content. Common scenarios:

- Reviewer-creators whose brand is built on "I don't take money"
- Journalist-adjacent creators who treat sponsored content as conflict-of-interest
- Subculture creators in audiences hostile to commercial content

The skill flags these patterns from pasted post context — if the creator has expressed "I don't take sponsorships" or shows zero #ad content historically, recommend gifted-only (and accept that posting is not guaranteed).

## When disclosure helps conversion

In some niches, transparent disclosure helps conversion:

- Wellness / health creators with savvy audiences: "I'm being paid to talk about this, here's what I actually think" frames brand-paid content as more credible
- Tech reviewer creators: paid disclosure + honest critique = trust
- Beauty creators: paid disclosure + side-by-side comparison = effective

The skill recognizes these patterns and recommends framing the disclosure as a positive trust signal in those contexts.

## Disclosure for affiliate-only relationships

When the brand offers an affiliate-only relationship (no upfront payment; only commission on referrals):

- Skill flags this as a separate framework
- Disclosure language must include affiliate commission mention
- Brand provides tracked link + commission rate (typically 8-15%)
- Creator's content can include affiliate link in bio / linked in post

Affiliate alone isn't usually compelling for nano/micro creators (no upfront value); works better for mid-tier+ creators with high-converting audiences. The skill outputs affiliate as an add-on to other frameworks, not as a standalone.
