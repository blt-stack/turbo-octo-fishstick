## Step 2: Pitch selection

Single SKU pitch (the brand's hero pour-over) — not a bundle. Macro creators with this much equipment-review credibility prefer to evaluate one product deeply.

The skill recommends pitching the integration format (sponsored segment within an existing video series) rather than dedicated video — significantly more affordable, often more authentic, and converts better with audiences who trust the creator's editorial frame.

---

## Step 3: Framework selection

- Tier: macro (2.8M)
- Buyer specified: paid partnership
- Cooling check: no prior cache entry; OK to outreach
- Manager-mediated outreach (skill auto-detected manager email)
- Suggested rate range: $15,000-$35,000 per dedicated video; $5,000-$12,000 per integration
- Recommendation: open at $8,000 for a single integration within a planned video, with option to scale to dedicated review if first integration performs

- Find manager contact: 15-45 min
- Write business-tier opening: 45-90 min
- Draft 3 follow-up variants with appropriate cadence: 60-90 min
- Document deliverables structure + disclosure requirements: 30 min
- **Total: 3.5-6 hours per macro outreach**

With this skill (after the buyer pastes context + manager email):
- Skill runs: ~5 seconds
- Buyer reviews + tunes brand-specific facts: ~15 min
- Brand deck attachment (pre-existing): 0 min if already built
- **Total: ~15 min per macro outreach**

The compounding value: even if 1 of 10 macro outreaches converts, the time saved across the 10 makes the entire macro program economically viable to run on a solo operator's schedule.
