# Etsy Listing Format

Etsy buyers shop for story as much as product. Maker context, materials, and process belong front and center. Algorithm rewards keyword-rich titles and tags but rewards craft language in the description.

## Structure

```
1. TITLE — Max 140 characters
   - Etsy SEO favors front-loading the primary keyword
   - Format: [Primary keyword/product type], [secondary keyword], [differentiator], [audience or occasion]
   - Separator: commas, pipes, or em-dashes — be consistent within a shop

2. DESCRIPTION — No hard limit, but first 160 characters appear as the meta description
   - Open with a sensory or use-case hook (NOT "Welcome to my shop!")
   - Section 1: What it is and what makes it special (story + materials)
   - Section 2: Details (size, materials, what's included)
   - Section 3: Care / use instructions
   - Section 4: Shipping & processing (if relevant — many Etsy shops repeat shop-wide info here)
   - Section 5: Return / custom-order info (if shop offers these)
   - Use ALL CAPS section headers — Etsy doesn't render markdown

3. TAGS — 13 tags max, 20 characters each
   - Mix of: product type, style, material, occasion, recipient, color
   - Use multi-word tags ("rustic wedding decor") not single words ("rustic")
   - No duplicates of words in title
```

## Voice notes

- Etsy is a story-led marketplace. Lead with origin, maker context, or sensory detail.
- Sentence length should vary — Etsy listings that read in one rhythm feel mass-produced (which kills conversion).
- First-person ("I", "we", "my studio") is welcome and trust-building. Use it.
- Personal asides work ("This is my favorite size — I keep one on my own desk"). Use sparingly.

## Pitfalls

- **Generic openers.** "Handmade with love" / "Perfect gift" appear in 60% of Etsy listings. Don't.
- **Buried materials.** Etsy buyers want to know what it's made of in the first paragraph, not buried under three sections of story.
- **Repeating shop-wide info verbatim** in every listing — Etsy buyers see the shop page already. Repeat only what's relevant per item.
- **Over-tagging with single words.** Two-word and three-word tags outperform single words for long-tail discovery.
- **Forgetting occasion/recipient tags.** Etsy traffic skews gift-shopping. "Anniversary gift" and "for new mom" tags pull queries that broad-category tags miss.

## Variant tactics

For the two Etsy variants:
- Variant 1: Story-led opener (a sentence about why this exists or how it gets made), then specs
- Variant 2: Sensory/use-case opener (paint the scene of the buyer using it), then specs

Both should keep the same tags and title structure — only the description voice changes.
