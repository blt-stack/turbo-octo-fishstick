# TikTok Shop Listing Format

TikTok Shop listings live inside a discovery-driven, video-first commerce platform. Buyers arrive via a creator video or a For You Page browse — they're already half-sold by the time they hit the product detail page. Copy's job is to confirm the impulse, not convince from scratch.

## Structure

```
1. PRODUCT NAME — Max 34 characters (this is short — really short)
   - Front-load the product noun + one differentiator
   - Skip the brand name unless the brand IS the hook
   - Example: "Velvet Hair Claw Clip 4-Pack" (28 chars)
   - Avoid emoji in title (some categories flag)

2. PRODUCT DESCRIPTION — Max 800 characters
   - First 100 chars are above the fold on mobile — make them count
   - Open with the use case or transformation, not a feature list
   - Short paragraphs (2-3 lines max). Line breaks > walls of text.
   - Emoji used sparingly is OK and on-platform — 1-2 per listing, not per line

3. PRODUCT ATTRIBUTES — Category-specific structured fields
   - Material, size, color, target audience
   - TikTok uses these for the recommendation engine
   - Generate as a separate list for buyer to enter in Seller Center

4. HASHTAGS / KEYWORDS (where shown) — short, scrollable, niche
   - Format like TikTok video hashtags: #productname #usecase #audience
```

## Voice notes

- TikTok Shop's audience skews Gen Z and younger Millennials.
- Voice is conversational, fast, slightly hyperbolic but not in a salesy way — closer to how a friend would describe the product.
- "POV" framing works ("POV: you finally found the moisturizer that doesn't break you out").
- Trend-aware language is OK but date-stamps the copy fast. Use sparingly and only if the brand voice supports it.
- Avoid corporate or marketing-speak — TikTok buyers can smell it.

## Pitfalls

- **Title over 34 chars** — gets truncated mid-word on mobile.
- **Long paragraphs** — TikTok readers don't scroll walls of text. Three short paragraphs > one long one.
- **Polished, agency-style copy** — reads as inauthentic on this platform. The voice should feel like a real person who genuinely likes the product.
- **Repeating the title in the description opener** — wasted real estate above the fold.
- **Heavy emoji use** — feels spammy. 1-2 strategic emoji, max.
- **External links anywhere** — TOS violation.

## Variant tactics

For TikTok Shop variants, the angle pairs that work best:
- Variant 1: POV/transformation opener ("POV: [scenario]")
- Variant 2: Problem-named opener ("Tired of [thing]? This is the fix")

Title can stay the same across both — only the description opener and body change.
