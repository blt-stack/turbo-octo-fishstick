# Walmart Marketplace Listing Format

Walmart Marketplace listings sit on a value-driven, family-shopping platform. Copy reads more functional than Amazon and far more functional than Etsy. Walmart's "Listing Quality Score" rewards completeness — every attribute filled, every spec captured.

## Structure

```
1. PRODUCT NAME (TITLE) — Max 200 characters; 50-75 sweet spot
   - Formula: [Brand] + [Clear Product Name] + [Key Attribute(s)] + [Pack Size/Quantity]
   - Walmart down-ranks keyword stuffing harder than Amazon does
   - No special characters or symbols
   - Singular and concrete: "Stainless Steel Insulated Water Bottle 32 oz" beats "Premium Sleek Modern Stainless Steel Water Bottle for Hydration"

2. KEY FEATURES — 3-10 bullets, max 80 characters each (yes, shorter than Amazon)
   - Front-load the benefit
   - Plain language — Walmart's audience is broader than Amazon's
   - No marketing fluff ("amazing", "incredible") — Walmart's algorithm flags it

3. DESCRIPTION — 150-300 words sweet spot, no hard limit
   - Plain prose. Walmart strips most formatting.
   - Cover: what it is, who it's for, key features, what's in the box, materials
   - End with care/use instructions if applicable
   - No CTAs, no external URLs

4. ATTRIBUTES / SPECS — Walmart-required structured fields
   - Fill all category-specific attributes Walmart asks for
   - These drive search and filter, not the description text
   - Generate a list of recommended attributes for the buyer to copy into Walmart Seller Center
```

## Voice notes

- Walmart's audience skews family, value-conscious, mid-America. Copy that's too cheeky or too aspirational underperforms here.
- "Plainspoken" is the safest voice register. Witty is fine if the brand voice supports it; ironic or sarcastic falls flat.
- Cite use cases and family scenarios where natural ("Big enough for a family roast", "Fits the school-day routine"). These connect with the platform's shopper base.

## Pitfalls

- **Title over 200 chars** — listing fails QA.
- **Marketing fluff in bullets** — Walmart's content team flags "best", "amazing", "perfect" as low-quality.
- **Skipping attributes** — directly drops the Listing Quality Score, which directly drops search ranking.
- **Mentioning competitors or other platforms** — TOS violation.
- **Pricing language in copy** — Walmart controls price display.

## Variant tactics

Two-variant strategy:
- Variant 1: Use-case forward (open with "Perfect for [scenario]")
- Variant 2: Spec forward (open with material and key feature)

Both should use the same title, same attributes — only the description body and bullet order differ.
