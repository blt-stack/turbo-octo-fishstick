# eBay Listing Format

eBay buyers are searching for specific items with clear specs. Title and item-specifics carry the search algorithm; the description is for closing the sale once they've clicked.

## Structure

```
1. TITLE — Max 80 characters
   - Use all 80 if you can — eBay's algorithm weights title heavily
   - Formula: [Brand] [Model/Item Type] [Condition] [Key Spec] [Size/Color] [Year/Generation]
   - No symbols, no ALL CAPS for emphasis, no "L@@K", no "WOW"
   - Skip filler words ("the", "a", "for sale")

2. ITEM SPECIFICS — eBay-required structured fields
   - Fill EVERY relevant field eBay offers for the category
   - These are weighted higher than description text for search
   - For a generated description doc, list out the recommended item-specifics so the buyer can copy into eBay's form

3. DESCRIPTION — No character limit, but eBay strips most HTML/JS on mobile
   - Open with item condition statement (critical for trust)
   - Bullets for key features, specs, what's included
   - Paragraph for condition details — be honest about flaws, even minor
   - Mention return policy and shipping in plain text
   - For used items: note any wear, missing pieces, repairs

4. CONDITION NOTE (for used/refurbished items)
   - Granular detail wins. "Like new, used twice, one tiny scuff on bottom rim from storage" beats "very good condition" every time
```

## Voice notes

- eBay copy is functional first, brand voice second. Buyers want trust signals (precise condition language, complete specs) more than personality.
- Light brand voice OK in the bullets and the "why you'll like it" closer. Stay measured — eBay buyers are skeptical by default.
- Use plain language. eBay's audience skews older and more value-conscious than Etsy or TikTok Shop.

## Pitfalls

- **Over-promising condition.** "Mint" and "perfect" set up returns. Be precise.
- **Skipping item specifics.** Items with incomplete specifics show up in fewer searches.
- **Decorative HTML.** eBay strips most of it on mobile. Use plain text and bullet symbols (• or –).
- **Linking offsite.** Against TOS.
- **All-caps emphasis.** eBay flags it as spammy and downranks.

## Variant tactics

For eBay, two variants is overkill for most sellers. Default to one polished version with thorough item-specifics. If the buyer asks for two:
- Variant 1: Spec-forward (open with condition + key specs, then bullets)
- Variant 2: Use-case forward (open with who it's for and what they'll do with it, then specs)

Title and item-specifics stay the same across both — only the description body differs.
