# Ad Angle Archetypes for Paid Creative

The 5 archetypes mirror skill #6's hook archetypes by design — buyers running both skills get a unified creative-and-ads angle library. The hooks coordinate; the contexts differ.

This file defines the 5 archetypes specifically for *paid ad copy* (ad caption, headline, description). The corresponding creator-script versions live in skill #6's `hook-archetypes.md`.

## Why 5 archetypes

Most "test 5 ad variants" attempts test 5 wordings of the same idea. Real angle diversity tests 5 distinct arguments. The 5 archetypes here represent 5 different reasons a shopper would click — pain relief, social proof, transformation, curiosity, or contrarian conviction.

When the buyer launches all 5 in Ads Manager and tests for 7-14 days, they learn which *argument* their audience responds to. That insight generalizes beyond this campaign.

## Archetype 1: Problem-aware (paid version)

**The angle:** Name a pain the audience already feels in their own words, then position the product as the fix.

**Best for:** Problem-solution products, audiences already searching for relief, lower-funnel cold traffic.

### Meta ad copy structure (problem-aware)

```
Primary text (125):
[Specific pain stated in audience's words]. [Product] is what happens when
someone actually solves it. [One-line value prop].

Headline (27): [Pain → product solution in 27 chars]

Description (27): [Practical reassurance — guarantee, ships, etc.]
```

### Example for the pour-over

```
Primary text (122/125):
I bought a $400 espresso machine and it lives in a cabinet because brewing
coffee at home felt like a chore. The pour-over fixed that in one Saturday.

Headline (27/27): The $400 mistake fixer

Description (26/27): Free shipping over $50.
```

### TikTok ad caption (problem-aware, 100 chars)

```
my $400 espresso machine lives in a cabinet now & i'm not even mad about it
(95 chars)
```

### Google RSA headline examples (problem-aware angle)

```
H1: Stop Wasting on Coffee Machines (29/30)
H2: Brews One Cup, Zero Drama (27/30)
H3: Coffee, Made Simple (19/30)
```

### Writing rules for problem-aware ad copy

- Use the audience's actual language (pulled from reviews when available)
- Specific pain beats vague pain ("$400 espresso machine in a cabinet" > "I had trouble making coffee")
- Don't over-agitate — one sentence of pain in a 125-char caption is enough
- The product mention should feel like a relief, not a sales pitch

### Don'ts

- Don't open with "Are you tired of...?" (self-parody at this point)
- Don't pretend a pain the audience doesn't actually feel
- Don't lead with the product (lead with the problem)

## Archetype 2: Social-proof (paid version)

**The angle:** Lead with credibility. Numbers, press, expert mentions, or "everyone's doing this."

**Best for:** New brands in mature categories, skeptical audiences, high-ticket items where shoppers default to risk-averse.

### Meta ad copy structure (social-proof)

```
Primary text (125):
[Specific credibility marker — review count + named publication + expert].
Here's why [N+] people switched. [One-line summary of what makes it work].

Headline (27): [Credibility marker in 27 chars]

Description (27): [Reinforce trust — guarantee, returns]
```

### Example for the pour-over

```
Primary text (124/125):
1,247 5-star reviews and a Sprudge 2026 pick. The handmade ceramic pour-over
that has coffee shop owners ordering it for their own kitchens. $68.

Headline (24/27): 1,247 reviews · Sprudge

Description (26/27): 30-day money-back guarantee.
```

### TikTok ad caption (social-proof)

```
12k people switched. the pour-over they all ended up with is hand-thrown ceramic.
(86 chars)
```

### Google RSA headline examples (social-proof angle)

```
H1: 1,247 5-Star Reviews on Etsy (30/30)
H2: Sprudge 2026 Pick (18/30)
H3: 12k Switched - See Why (24/30)
```

### Writing rules for social-proof ad copy

- Numbers should be exact and specific (1,247 > "many")
- Credentials should be relevant to the category (a chef quote for cookware, not skincare)
- Never fabricate — overpromise here destroys brand credibility on contact
- Combine credentials when possible (review count + press = stronger than either alone)

### Don'ts

- Don't lead with vague claims ("trusted by thousands")
- Don't use credentials the brand doesn't actually have
- Don't lean on celebrity endorsements unless the celebrity is genuinely associated

## Archetype 3: Transformation (paid version)

**The angle:** Show the after-state. Paint the future version of the audience's day.

**Best for:** Aspirational/lifestyle products (beauty, fitness, home decor, productivity), audiences that resonate with "I want my life to look like this."

### Meta ad copy structure (transformation)

```
Primary text (125):
[Specific sensory snapshot of the after-state]. [How the product gets you
there]. [Reassurance about the time/effort cost].

Headline (27): [Outcome restated in 27 chars]

Description (27): [Practical proof — time-to-result, etc.]
```

### Example for the pour-over

```
Primary text (123/125):
Slow Saturday mornings. One cup. Three minutes. Hand-thrown ceramic pour-over,
reusable mesh filter, dishwasher safe. The coffee setup you'll actually use.

Headline (27/27): Saturday morning, finally

Description (24/27): Ships in 2 business days.
```

### TikTok ad caption (transformation)

```
mornings hit different when you actually want to make coffee
(58 chars)
```

### Google RSA headline examples (transformation angle)

```
H1: Slow Mornings Start Here (24/30)
H2: One Perfect Cup, Three Min (27/30)
H3: The Pour-Over You'll Use (24/30)
```

### Writing rules for transformation ad copy

- Make the after-state sensory and specific ("Slow Saturday mornings" > "feel good")
- Anchor in a moment, not a feeling (a scene > a mood)
- The after-state should feel achievable, not impossible
- The "how" should be concrete (hand-thrown ceramic + included filter + dishwasher safe)

### Don'ts

- Don't promise overnight transformation
- Don't use stock-image abstractions ("a better you," "the life you deserve")
- Don't paint a transformation that constitutes a regulated claim (medical, financial)

## Archetype 4: Curiosity-gap (paid version)

**The angle:** Set up an unanswered question or unexpected premise. The viewer needs to keep reading (or click) to resolve.

**Best for:** Products with non-obvious value, crowded categories where the buyer needs to stand out, audiences that scroll past direct-sell ads.

### Meta ad copy structure (curiosity-gap)

```
Primary text (125):
[Surprising claim or unexpected setup]. [Reveal that needs more explanation].
[Soft CTA: "Here's why" / "Find out how"].

Headline (27): [The mystery, condensed]

Description (27): [Soft promise of the reveal]
```

### Example for the pour-over

```
Primary text (120/125):
I'd been making pour-over wrong for two years and didn't know until this
arrived. The fix wasn't grind, or technique, or beans. It was the dripper.

Headline (24/27): Was making coffee wrong

Description (24/27): The dripper that fixed it.
```

### TikTok ad caption (curiosity-gap)

```
turns out i'd been making pour-over wrong for years. it was the dripper.
(72 chars)
```

### Google RSA headline examples (curiosity-gap angle)

```
H1: The Pour-Over Mistake (20/30)
H2: Two Years of Bad Coffee (23/30)
H3: It Wasn't the Beans (19/30)
```

### Writing rules for curiosity-gap ad copy

- The gap must resolve on the landing page — never leave the reader hanging without payoff
- The setup should be specific (vague "you'll be shocked" gets ignored)
- Most effective with educational / story-led products; less so with pure product showcases

### Don'ts

- Don't manufacture mystery where there isn't any
- Don't promise more than the destination delivers (kills trust + raises bounce rate)
- Don't use clickbait-style cliffhangers ("you won't believe what happens next!")

## Archetype 5: Contrarian (paid version)

**The angle:** Challenge a common belief in the category. The audience has to listen to defend their existing view or to learn a better one.

**Best for:** Categories with strong prevailing wisdom the brand is positioned against (slow vs fast, expensive vs cheap, traditional vs modern, single-use vs reusable).

### Meta ad copy structure (contrarian)

```
Primary text (125):
[Direct challenge to a common belief]. [Reason it's wrong, or what's actually
true]. [Where the product fits as the alternative].

Headline (27): [Contrarian position in 27 chars]

Description (27): [Reinforce the position]
```

### Example for the pour-over

```
Primary text (120/125):
Espresso machines are over. The actually-good way to make coffee at home is
hand-brewed pour-over, in 3 minutes, with no cleanup beyond a rinse.

Headline (26/27): RIP your espresso machine

Description (27/27): Hand-thrown ceramic. $68.
```

### TikTok ad caption (contrarian)

```
unpopular opinion: espresso machines are over
(45 chars)
```

### Google RSA headline examples (contrarian angle)

```
H1: Espresso Machines Are Over (27/30)
H2: Better Coffee Without (22/30)
H3: Hand-Brewed, Three Min (22/30)
```

### Writing rules for contrarian ad copy

- The contrary position must be defensible (the brand should actually believe it)
- Be specific about what you're contradicting
- Avoid attacking specific competitors by name (TOS + legal risk)
- Best for audiences who already have some skepticism about the dominant category

### Don'ts

- Don't be contrarian for its own sake — the position has to be substantive
- Don't be mean-spirited about the prevailing view (alienates viewers who hold it)
- Don't make claims you can't back up (contrarian positions get fact-checked harder)

## Voice consistency across archetypes

The 5 archetypes test different angles, but the **brand voice stays constant** across all 5. A calm/considered brand's contrarian ad reads differently from a bold/punchy brand's contrarian ad — same archetype, different voice.

When generating the 5 concepts, the skill:

1. Loads the brand voice from `config.brand_voice`
2. Writes each archetype's copy in that voice
3. Adjusts the archetype's natural energy to match the brand (e.g., contrarian for a calm brand is principled rather than confrontational)

---

## When the buyer asks for fewer archetypes

If the buyer says "just give me 3 concepts" or "skip the contrarian, my brand doesn't do that," honor the override. Note it in the brief ("Skipped Contrarian per buyer request — generated 4 concepts instead of 5").

If the buyer asks for more than 5, generate 2 concepts per archetype (10 total) using meaningfully different hooks within each archetype. Don't go beyond 10 — test signal degrades.
